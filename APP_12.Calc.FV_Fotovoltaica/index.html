🌡️ 1. Temperaturas de Operación
FRÍO Peor escenario de frío
T_cell_min = T_amb_min → máxima tensión (criterio seguridad)
CALOR Peor escenario de calor
T_cell_max = T_amb_max + 25 → mínima tensión + máxima corriente
Regla práctica (+25°C). Alternativa: T_cell = T_amb + (NOCT − 20) × G/800
⚡ 2. Tensiones
SEGURIDAD Tensión Máxima — por inversor
V_max = Voc_STC × [ 1 + ( βVoc/100 × ( T_amb_min − 25 ) ) ] V_max_string = V_max × N → < Vdc_max_inversor[i] N_max[i] = floor( Vdc_max[i] / V_max_unitaria )
FUNCIONAMIENTO Tensión Mínima — por inversor
V_min = Vmpp_STC × [ 1 + ( βVoc/100 × ( T_cell_max − 25 ) ) ] V_min_string = V_min × N → Vmpp_min[i] ≤ V_min ≤ Vmpp_max[i] N_min[i] = ceil( Vmpp_min[i] / V_min_unitaria ) Nota: V_max_u y V_min_u son iguales para todos los inversores (módulo único). El rango [N_min, N_max] puede diferir por inversor si tienen distinto Vdc_max o Vmpp_min.
🔌 3. Corrientes y Potencia
DIMENSIONADO Corrientes en caliente — comunes a todos los inversores
Isc_max = Isc_STC × [ 1 + ( αIsc/100 × ΔT_hot ) ] Impp_real = Impp_STC × [ 1 + ( αIsc/100 × ΔT_hot ) ] I_diseño = 1,25 × Isc_max [UNE-HD 60364-7-712] Por inversor: Verificar: Isc_max × n_ch[i] ≤ Imax_MPPT[i]
DERATING Potencia real — por inversor
P_real_mod = Pmax × [ 1 + ( βPmpp/100 × ΔT_hot ) ] [común] P_real[i] = P_real_mod × n_mod[i] / 1000 [kW] ratio_real[i]= P_real[i] / Pac[i] clipping[i] = ratio_real[i] ≥ 1,0 Planta completa: Pdc_total = Σ Pdc[i] Pac_total = Σ Pac[i] P_real_total = Σ P_real[i]
📐 4. Caída de Tensión CC
CDT Fórmula por tramo
I_diseño = 1,25 × Isc_max [UNE-HD 60364-7-712] ρ = 0,024 Ω·mm²/m [Cu exterior PV1-F] cdt_V = 2 × L × I_diseño × ρ / S cdt_% = (cdt_V / V_max_string) × 100 CDT_total_% = Σ cdt_%(tramos activos) ≤ 1,5 % S=0 mm² → tramo inexistente, CDT=0 (excluido del total) S_mín proporcional: CDT_disp_tramo = V_string × 0,015 × (L_tramo / L_total_activa) S_min = 2 × L × I_diseño × ρ / CDT_disp_tramo
🏭 5. Nomenclatura Multi-Inversor
Identificadores de string y línea CC
Formato string: INV[ii]-MPPT[m]-[cc] ii = nº inversor 2 dígitos (01, 02, ...) m = nº MPPT sin ceros (1, 2, ...) cc = nº canal 2 dígitos (01, 02, ...) Ejemplos: INV01-MPPT1-01 → Inversor 1, MPPT 1, Canal 1 INV01-MPPT2-03 → Inversor 1, MPPT 2, Canal 3 INV02-MPPT1-01 → Inversor 2, MPPT 1, Canal 1 Identificador CC: INV[ii]-MPPT[m]-[cc] Tramo CC
